# Pydantic AI Learning

A personal learning project for experimenting with [Pydantic AI](https://ai.pydantic.dev/), a Python framework for building production-grade applications powered by generative AI and LLMs.

## About

This repository contains experiments, examples, and learning notes as I explore Pydantic AI's capabilities, including:

- Building AI agents with type safety
- Working with different LLM providers
- Understanding Pydantic validation with AI models
- Exploring best practices for agent development

## Setup

This project uses [uv](https://github.com/astral-sh/uv) for dependency management.

```bash
# Install dependencies
uv sync

# Run examples
uv run python basic/simple-agent.py
```
